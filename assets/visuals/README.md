# Short Order visual set

Four high-resolution illustrations in the warm café language the interface uses:
cream paper, cocoa ink, terracotta, berry and butter, drawn as clay-and-painted-wood
miniatures. They contain no embedded labels, so slide copy can be positioned and
localised independently.

| Asset | Size | Best use |
| --- | ---: | --- |
| `short-order-hero-warm.png` | 1823 x 863 | Dashboard hero, title slide, course banner |
| `kitchen-scheduler-metaphor-warm.png` | 1536 x 1024 | Explaining cook/core, order/process, ready/running/blocked |
| `context-switch-cost-warm.png` | 1536 x 1024 | Preemption and context-switch teaching slide |
| `scheduling-policy-comparison-warm.png` | 1536 x 1024 | FIFO/SJF/RR/EDF comparison or discussion prompt |

`short-order-hero-warm.png` is the one the launcher and the arena serve, behind a
light warm scrim on its left third. It is composed for that: the left 38 per cent
is quiet cocoa wall with nothing in it to read past.

The original dark set - `short-order-hero.png` and its three companions, without
the suffix - is kept alongside these. It matches the charcoal-and-neon interface
the platform used before the warm café restyle, and nothing serves it now.

All eight are original AI-generated bitmap assets. Keep labels as native slide or
web text for accessibility and crisp rendering. The generation specifications are
recorded in [`PROMPTS-WARM.md`](PROMPTS-WARM.md) for the warm set and
[`PROMPTS.md`](PROMPTS.md) for the dark one.
